Left undocumented, matching this task's established tier-1-scope precedent: brand-new commands the wiki added in this range that have no dictionary entry at all (M140.1, M581.1, M952, M953, M954, M959, M970/M970.3, M36.2, M505.1, M558.3, M558.4), and parameter additions on commands that were never reviewed to begin with (M107 F, M115, M118 P enum, M141, M404, M576, M582, M594, M667, M915, M916, M953, M997) - these remain draft-only or unreviewed by design, not gaps in this pass.
